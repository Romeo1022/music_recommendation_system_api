# Music Recommendation System API

## Description
A REST API that provides music recommendations based on user preferences.

## Tech Stack
- Node.js
- Express.js
- MySQL
- JWT Authentication
- Postman (API Testing)

## How to Run
1. Open the project folder in VS Code.
2. Navigate to the music-recommendation-system folder.
3. Run `npm install`.
4. Configure the database and environment variables.
5. Run the server using the project's start command.
6. Test the API using Postman.
